## [twotower-v1.0.0] — Pre-Release Candidate

### Added

- **Headless Dual-Tower Engine & Checkpoint Metadata (`src/twotower/{spec,modulation,sampler,parameters,contracts,execution}.ts`)**: Clean-room TypeScript implementation of `NemotronHTwoTowerForCausalLM` grounded in [`arXiv:2606.26493v2`](https://arxiv.org/abs/2606.26493) and Hugging Face `nvidia/Nemotron-Labs-TwoTower-30B-A3B-Base-BF16` pinned at revision `35b6498508be8856d380cdfe4a900a79b918d1ea`. Includes exact `0`-byte analytical vs. 24-shard safetensors payload reconciliation (`63,185,902,848` params / `126,371,817,472 B` = `126.37 GB` SI / `117.69 GiB` IEC), a 9-entry paper-vs-checkpoint discrepancy ledger, split PixArt-α `adaLN-single` ordering (`modulate → RMSNorm` on `M`/`*` vs. `RMSNorm → modulate` on `E`, unmodulated `norm_f`), FP64 MoE routing (`--moe-router-dtype fp64`), unshifted MDLM/SUBS confidence unmasking with deterministic Gumbel-max, and non-aliased `TwoTowerContextSnapshot` / read-only `TwoTowerContextConditioningState` ownership contracts across `AR`, `Mock-AR`, and `Mask-Diffusion` modes.
- **Independent PyTorch `2.15.0` Parity Suite (8 Categories)**: Offline clean-room reference generator (`scripts/reference/export_twotower_params.mjs`, `scripts/reference/generate_twotower_pytorch_fixtures.py`) and 3 checked-in fixtures (`tests/fixtures/pytorch-twotower-{blocks,handoff,trajectory}-parity.json`) verifying timestep/split-adaLN + order-inversion sensitivity, bidirectional `[B × (P+B)]` GQA, seeded & `O(1e3)` FP32 Mamba-2, FP64 MoE near-tie/exact-tie routing, complete 52-layer handoff (`0`-ULP Context immutability), 2-block diffusion trajectory, AR vs. Mock-AR `0`-ULP identity parity, and MDLM/Gumbel sampler edge cases.
- **Immutable Session Store & Branching (`src/twotower/session.ts`)**: Copy-on-step `TwoTowerSession` supporting the 4-step block diffusion lifecycle (`Init` → `Refine` → `Commit Conf` → `Completed (Uncommitted)` → `Commit → Context`), `AR` and `Mock-AR` steps, non-destructive cursor scrubbing, auto-forking from rewound history, active-branch-safe deletion, and bounded memory retention.
- **Seven Interactive WebGL2 Spatial Views (`src/twotower/scene/`, `src/twotower/app/`)**: Dedicated Topology A `/twotower/` visualizer featuring **Macro** (`52×2` dual towers, 29 aligned transfer linkers vs. 23 stateless MoE bays, instructional Macro Flow Replay), **GQA** (asymmetric 35/65 paired view, `128×128` RG32F atlas packing all 32 Q + 2 KV heads, bidirectional `[B × (P+B)]` attention), **Mamba** (asymmetric 35/65 paired view, `256×128` RG32F atlas packing all 16 heads / 8 groups + native `4×4` analytical SSM decomposition and 4-tap Conv1D boundary replacement `3→2→1→0`), **Timestep** (`t = nMasked / B`, split `adaLN-single`), **MoE** (`128+1` stateless bank, FP64 6th-vs-7th margin, non-spoiling partial `Σσ` denominator), **Embed** (independent untied NoPE `V = 34`), and **Output** (unmodulated `norm_f`, untied LM head, zero-`Infinity` MDLM probabilities).
- **Persistent Nested Timeline, Advanced MDLM Sampler & Developer Workbench**: Bottom nested timeline dock with branch selector/fork/delete/restart and milestone scrubbing; Advanced Sampler inspector (`0.22` mini default / `0.80` paper / `0.90` reference code presets, decoupled `B ∈ {4, 8}` and `K ∈ [1..12]`, explicit non-retroactive config scope badges, calibration caveat); and collapsible bidirectionally synced Developer Diagnostic Workbench (`W`).
- **Isolated 4-Act / 28-Beat Guided Walkthrough (`src/twotower/story/walkthrough.ts`)**: Self-contained educational tour (`T`) spanning Dual-Tower Architecture & Modes, Conditioning & Paired Layers, Denoiser Output & MDLM Sampler, and Context Commitment & Production Architecture, restoring the user's Free Explore session untouched on exit.
- **Production Architecture & 3-Regime Context-Length Scaling Readouts (`src/twotower/archReadouts.ts`)**: Dual SI (`GB`/`MB`) & IEC (`GiB`/`MiB`) checkpoint inventory including FP32 `e_score_correction_bias` (`46` tensors / `5,888` params / `+11,776 B`), explicit 4-way memory separation (Persistent Context Cache vs. Optional Snapshots/Mirrors vs. Transient Denoiser Block KV vs. Excluded Peak Inference Runtime Workspace), 3-regime context-length scaling (`≤ 128K` Model-Card Operational · `128K–256K` Configured Positional Limit · `> 256K` Analytical Extrapolation), discrepancy ledger, and non-official community NVFP4 reference note.
- **Topology A MPA, Quiet Reciprocal Navigation & Release Documentation**: Multi-entry Vite build (`/` Nano + `/twotower/` TwoTower) with 7-gate Nano bundle-isolation verification (`scripts/verify_bundle_isolation.mjs`) enforced identically on both `/` and `/llm-viz/` builds in CI and Pages deploy (`212,585 B` / `207.60 KiB` Nano gzip vs. `215.00 KiB` budget with `7.40 KiB` headroom, `130,321 B` / `127.27 KiB` shared `assets/overlay-*.js` gzip [`442,996 B` raw, `0` TwoTower sources], `325,382 B` / `317.76 KiB` TwoTower gzip across `22` `src/twotower/*` modules); quiet base-path-aware reciprocal links (`TwoTower ↗` / `Nano ↗`, `+77 B` Nano CSS gzip / `0 B` Nano JS, guarded by `tests/twotower-navigation-contract.test.ts` [`3` tests] and E2E Test 12); [`docs/TWOTOWER_ARCHITECTURE.md`](docs/TWOTOWER_ARCHITECTURE.md), [`docs/TWOTOWER_USER_GUIDE.md`](docs/TWOTOWER_USER_GUIDE.md), [`docs/RELEASE_NOTES_TWOTOWER_v1.0.0.md`](docs/RELEASE_NOTES_TWOTOWER_v1.0.0.md), updated [`docs/VERIFICATION.md`](docs/VERIFICATION.md), [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md), and [`README.md`](README.md).

## [1.0.0] — 2026-11-24

### Added

- **52-Layer Hybrid Vertical Tower**: Full WebGL2 3D spine derived directly from Hugging Face `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16/config.json` (commit `bf77c3174f68ad409e1c2aa60daeb46e32d1c606`, `23 Mamba-2 · 23 MoE 128+1 · 6 GQA Attention`), four NVIDIA Figure 2 motif spans (`01–35`, `36–41`, `42–44`, `45–52`), continuous `2,688`-channel emerald residual stream, and untied Embedding / Output bookends.
- **Unified 52-Layer Float32 Miniature Simulator (`src/math/hybridFlow.ts`)**: Deterministic clean-room Float32 forward pass (`d = 8`, `V_mini = 32`, `ε = 1e-5`) spanning Embedding (NoPE) → all 52 layers → Final RMSNorm → Untied LM Head + Softmax, verified against independent **PyTorch `2.15.0`** reference fixtures with SHA-256 weight proofs (`scripts/reference/`, `tests/fixtures/`).
- **Cached Incremental Autoregressive (AR) Decoding & Branching (`src/math/incrementalDecode.ts`, `src/math/cacheContracts.ts`)**: `Full Seq` vs. `AR Decode` mode toggle, prefill + single-token AR steps with bit-exact (`0` ULP) full-sequence equivalence, immutable copy-on-step `HybridDecodeCacheState` snapshots (`75.00 KiB` default miniature snapshot), rewind/fork continuation branches, and isolated Tour vs. Free Explore sessions (`DualDecodeSessionStore`).
- **Five Exploded 3D Layer Cutaways**: Dedicated 3D thin-sheet cutaways with live `RG32F` value atlases and interactive Math Dock inspection for **Embedding (NoPE)**, **Mamba-2 (Bay 01 & Bay 42 Feeder)**, **Granular MoE 128+1 (Bay 02 & Bay 52)**, **GQA Attention 32Q/2KV (Bay 06 & Bay 43)**, and **Output / LM Head (Top-5 strip)**.
- **Focused-Cell Partial-Sum Accumulation & Non-Spoiling Reveal**: Operand-by-operand cutaway stepper (`~400 ms/term`), running partial sums in Math Dock / floating popover / zoomed tensor cells, and running MoE sigmoid denominator (`Σσ`) without premature normalized weight exposure.
- **22-Beat, 3-Act Guided Walkthrough (`src/story/walkthrough.ts`)**: Non-destructive interactive tour (`Act I · Full-Sequence Prefill`, `Act II · Precision Boundary`, `Act III · Live Cached AR Decode & 1M Scaling`) plus fast (`0.9 s`) and slow instructional (`5.5 s`) 52-layer Tower spine propagation replay with pauseable HUD.
- **Selective FP8 Mode & Interactive `1 → 1M` Memory Scaling Chart**: Live `[ BF16 | FP8 Selective ]` toggle highlighting NVIDIA §4.2–4.3 preservation boundaries (12 BF16 bays + 23 BF16 Conv1D strips + FP8 KV caches) and an inline zero-dependency SVG log-log scaling chart (`3.05 GiB` FP8 / `6.05 GiB` BF16 at 1M tokens vs. `26.0 GiB` / `52.0 GiB` 52-layer GQA).
- **Automated Verification & Release Documentation**: Playwright/Chromium WebGL2 E2E smoke suite (`npm run test:e2e`), separated PR verification CI (`.github/workflows/ci.yml`) and main-only Pages deployment (`.github/workflows/deploy.yml`), [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md), [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/VERIFICATION.md`](docs/VERIFICATION.md), and in-app attribution credits in `index.html`.

### Changed

- **Cache & Memory Hardening**: Raised default bay weight cache to all 52 bays (`~1.14 MiB`) sharing read-only `Float32Array` buffers across executions/traces; added length-prefixed `prefixTokenLabels` to `stateDigest`, isolated lazy-reconstruction closures, active-branch-safe branch deletion, and conservative session bounds (`maxBranches = 16`, `maxUniqueSteps = 128`, inactive trace pruning).
- **Runtime Rendering & Performance**: Consolidated all 8 cutaway builders onto shared 18-float `LinesPass` guide-line packing (`src/render/linePacking.ts`), gated continuous RAF strictly to active motion/playback, coalesced `pointermove` hover picking, deduplicated `RG32F` atlas uploads via `computeValueAtlasContentKey`, throttled 5.5 s spine-wave rebuilds to discrete bay transitions, and moved 60 fps stepper UI ticks onto `syncStepperProgressOnly()`.
- **Milestone 1 Briefs Archived**: Moved superseded Milestone 1 planning documents into [`docs/archive/DESIGN_BRIEF.md`](docs/archive/DESIGN_BRIEF.md) and [`docs/archive/IMPLEMENTATION_PLAN.md`](docs/archive/IMPLEMENTATION_PLAN.md).

### Fixed

- **Accessibility & Keyboard Parity**: Deferred global `Space`/`Enter` shortcuts when native buttons/controls have focus; added WAI-ARIA `role="tab"` + roving `tabindex` + arrow navigation on `.mode-pills` and `#gqa-step-pills`; added modal focus capture/trap and `Escape` focus restoration for `#shortcuts-popover` and `#memory-chart-drawer`; synchronized all shortcuts (`1–4`, `5`, `6`, `Space`, `Shift+Space`, `←/→`, `↑/↓`, `Enter`, `P`, `M`, `R`, `?`, `Esc`) and pre-hydration `Tour 1/22` copy across `index.html`, `src/main.ts`, and `README.md`.
- **WebGL Context-Loss Recovery & FBO Cleanup**: Prevented leaked FBO/renderbuffer handles on partial allocation failure (`fboAllocFailed` latch), paused all animation clocks on `webglcontextlost`, and reconstructed all 5 passes cleanly on `webglcontextrestored`.
- **Visual & Layout Polish**: Restored visible cutaway guide lines across all 8 builders, eliminated MoE premature weight exposure in Step 3 (`Top-6`), improved floating popover active-cell avoidance, ensured all 5 Output Top-5 candidate pills remain visible and non-overlapping, and tightened narrow (`1024×800`) and mobile (`390×844`) layout containment.
